# 接口发现运行时实施计划

> 日期：2026-06-23。该计划属于旧 BSCLI 原型，所有任务均已完成，所述运行入口现已退役。

## 目标

把保存在 `.bscli/discovered/<system>/apis/*.json` 中的接口元数据转换为可列举、可运行、
可导出清单的动态命令，为后续正式业务适配提供证据。

## 当时的技术路线

增加一个轻量接口发现存储层，从磁盘读取元数据并规范化为命令记录；CLI 提供发现接口的
列举、查看和运行能力；守护进程提供统一运行入口；工具清单可以选择性导出发现工具，且不
改变静态适配器注册方式。

技术栈为 Python 标准库、既有 BSCLI 命令行与守护进程模式以及 `unittest`。

## 历史结论

动态发现运行时适合快速验证接口线索，但不适合作为长期对外能力。当前 AgentBridge 已把
稳定契约迁入系统适配器和能力注册表；发现结果必须经过业务命名、权限、错误语义、审计和
真实验收后才可对智能体开放。
