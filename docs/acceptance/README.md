## 记录规则

- 文件名包含验收主题和日期；重大复验新增文件，不覆盖旧证据。
- 文档写明环境、版本、身份范围、是否读取真实业务数据、是否发生业务写入和最终判据。
- 自动化通过、真实页面通过和用户人工确认分开表述。
- 不在验收文档中保存凭据、Token、Cookie、完整个人敏感数据或短期交互 URL。
