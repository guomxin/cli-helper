## 文档治理约定

- `docs/项目当前状态.md` 是“现在做到哪里”的唯一汇总，不在多份设计中重复维护版本数字。
- 现行文档不追加流水账；有长期追溯价值的演进记录进入“历史归档”，验收证据进入“验收记录”。
- 系统专属内容放入 `docs/系统适配/<系统名称>/`，跨系统机制才放入“架构设计”或“平台能力”。
- 新验收使用 `主题-YYYY-MM-DD.md`；已发布的验收快照只做事实勘误，不改写当时结果。
- 移动文件或改名时必须更新链接并运行 `python -m unittest tests.test_documentation`。
- 文档不得包含密码、Bearer Token、Cookie、私钥、临时卡片 URL 或其他可复用秘密。
- 文档子目录、领域文件名和叙述正文统一使用中文；产品名、协议名、命令、接口和代码标识可以保留英文。
- 根目录及发布包中的 `README.md` 为 GitHub、NPM 等工具的约定文件名，正文仍使用中文。
