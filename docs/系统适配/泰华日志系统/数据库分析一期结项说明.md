# 日志数据库分析一期结项说明

更新：2026-09-10。技术交付与已授权两用户生产验收已完成，可进入用户手工复验和交接；本文件不代替用户签署验收结论。

## 交付范围

| 项目 | 当前交付 |
| --- | --- |
| 使用者 | 中央身份 guomao、lishiyu；仅本人数据，管理员也不能读取另一用户的分析结果或报告 |
| 数据口径 | DAILY 日报；单窗口 1—7 天，北京时间；登记工时、日志数、有登记人日、未关联项目统计、每日分组 |
| 功能 | 本人汇总、历史结果读取、两个窗口比较、每日 CSV 导出及认证下载 |
| 入口 | Workspace；已配置可信身份的 OpenClaw 私聊和认证 MCP。各端权限取决于绑定身份，不共用管理员身份 |
| 数据源 | xinguomao 数据库账号；analysis 下五个脱敏视图，当前执行器只查询 analysis.work_logs 的八个统计字段及系统目录元数据 |
| 权限策略 | strict，预检告警为空；源库凭据加密保存，应用鉴权和 API 前后可见性核验保留 |
| 结果交付 | 结果有效 7 天；下载引用 10 分钟；加密文件最多 24 小时且不超过来源寿命；每次下载重新鉴权 |
| 请求恢复 | 已接收请求断线后持续观察原 run，不重发；恢复期限 30 分钟，超时为结果未确认，不把它视为业务失败 |

五个数据库视图是可用数据边界，不代表应用已支持团队、项目、人员分析、正文归纳或评论分析。本期不提供自由 SQL、任意数据库连接和生产库写入；登记工时不等于考勤或绩效。
