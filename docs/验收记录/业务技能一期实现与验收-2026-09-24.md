# 业务技能一期实现与验收

日期：2026-09-24。状态：实施候选，发布与线上结果待补记。

## 实现范围

中央统一发布五个业务 Skill：日志总结与事项复核、事项进展追踪、相似案例检索、OA 事项生成日志、OA 待办办理。新增中央目录、规则读取、版本哈希与快照、用户及全局配置、审计、任务绑定和动态撤销。控制台按用户配置，工作台新增业务助手入口。宿主按需加载，不向用户设备安装 Skill 文件。

Skill 不增加底层权限。预览不进入写入，批量与单条功能分别配置；数据库依赖在同一个数据源满足。撤销后旧绑定不能被重新分配复活；执行授权消费在原 SQLite 事务内检查 Skill。常驻策略中的追踪和案例详细做法已提取，工具证据规则保留。

## 已执行验证

- 初轮业务 Skill、业务授权及 MCP 工具目录：20 项通过。
- MCP、管理控制台、计划写入边界、文档及 Skill：119 项、959 子测试通过。
- OpenClaw 业务 Skill、插件与多用户定向回归：160 项通过。首次发现旧合同不支持 Skill 时仍读取目录，已改为按中央 `skillProtocol` 协商加载后复测通过。
- 追加独立 Reference Host 真实 MCP、撤销事务与宿主兼容性：21 项、21 子测试通过；覆盖认证目录、规则加载、跨用户绑定拒绝、撤销后不进入业务执行及授权消费未发生。
- 控制台隔离 Chromium 测试：管理员保存预览配置，审计员只读；桌面与 390px 窄屏检查。测试账号、数据和业务地址均为本地夹具，不代表现网用户已分配。截图位于本地 `output/business-skills-browser`。

定向结果不是全量回归或真实业务验收。正式发布记录和实际用户配置将在执行后补记。

## 保留范围

- 未删除正文分析、评论分析或确定性转换入口；尚未证明读取、证据、预算和权限完全等价。
- 相似案例相关性限制继续保留，Skill 标记试用；不宣称此次提取改善了语义准确率。
- 未新增定时监控、任意脚本执行、多 Skill 编排或长期事项台账。
- 未因部署自动分配用户 Skill；实际分配遵循用户指定范围。未自动新增 OA 或泰华正式业务提交。
- 旧版本快照自动回收、第二批场景及独立人工模型质量评分未在本批完成。
