# 业务技能一期实现与验收

日期：2026-09-24。状态：已部署并推送；基础设施与宿主线上验收通过，实际用户分配及业务场景验收待完成。

## 实现范围

中央统一发布五个业务 Skill：日志总结与事项复核、事项进展追踪、相似案例检索、OA 事项生成日志、OA 待办办理。新增中央目录、规则读取、版本哈希与快照、用户及全局配置、审计、任务绑定和动态撤销。控制台按用户配置，工作台新增业务助手入口。宿主按需加载，不向用户设备安装 Skill 文件。

Skill 不增加底层权限。预览不进入写入，批量与单条功能分别配置；数据库依赖在同一个数据源满足。撤销后旧绑定不能被重新分配复活；执行授权消费在原 SQLite 事务内检查 Skill。常驻策略中的追踪和案例详细做法已提取，工具证据规则保留。
