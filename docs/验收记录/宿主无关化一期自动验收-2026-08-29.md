只使用公开远程 MCP 客户端，不导入 AgentBridge 业务内部模块。自动通过不代表已获得真实业务

- 管理端宿主登记、兼容版本、健康快照和 Lease 的脱敏展示；
- 读取与 `prepare` 有界恢复，副作用调用不自动重试。

## 四、重点故障向量

- 未登记或版本漂移的宿主最多获得 L1；
- Token A 携带 Token B 的 Endpoint 被拒绝；
- 非 Lease 持有者不能 resume；
- 完成通知早到、晚到或重复时只续办一次；
- 一个身份登记失败不影响另一身份；
- 过期 Artifact 不再暴露旧下载 URL，但可保留重生入口；
- 不完整远端恢复项不会生成孤儿任务；
- 运行快照被中央拒绝时记为失败信号，不伪装成健康；
- OpenClaw 原有 Telegram、微信、Workspace、多端卡片、文件和批量任务测试保持通过。
