## 五、重点故障向量

- 未登记或版本漂移的宿主最多获得 L1；
- Token A 携带 Token B 的 Endpoint 被拒绝；
- 非 Lease 持有者不能 resume；
- 完成通知早到、晚到或重复时只续办一次；
- 一个身份登记失败不影响另一身份；
- 过期 Artifact 不再暴露旧下载 URL，但可保留重生入口；
- 不完整远端恢复项不会生成孤儿任务；
- 运行快照被中央拒绝时记为失败信号，不伪装成健康；
- OpenClaw 原有 Telegram、微信、Workspace、多端卡片、文件和批量任务测试保持通过。

## 六、尚需分开记录的真实证据

真实 L2 登录卡纵切需要会话自然失效或使用专门测试身份；真实 L3 写入和可撤销验证不在无人值守
验收中执行，后续有合适目标时单独授权并记录。外部第三方 MCP 宿主接入仍属于二期候选工作。
