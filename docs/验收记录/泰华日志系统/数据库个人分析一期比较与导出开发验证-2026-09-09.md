# 数据库个人分析一期 B 开发验证

日期：2026-09-09。范围为当前仓库实现和本地验证；不表示已部署或已开启生产数据源。

## 交付范围

新增两窗口确定性比较转换、受控 CSV 生成与认证下载，补齐 Workspace 已登录文件下载及 OpenClaw 私聊附件交付。中央目录现为 108 个业务能力、151 个 MCP 工具。

比较计划固定为两个本人 summary 及一个比较转换。操作、计划、绑定和投影仅持久化受保护引用；读取比较结果重新核验两个来源。CSV 仅有每日数值、口径及查询时间，文件加密存储。下载引用十分钟，文件最多二十四小时且不超过来源寿命；MCP 和 Workspace 每次下载均需当前身份和导出授权。

同时修正完成的计划任务继续读取结果的路由，并支持团队 API 的嵌套 user.id；两个身份字段同时出现但冲突时拒绝，不退回姓名匹配。
