验收日期：2026-08-30  
线上 Release：`08d7ac09341a`

## 1. 验收目标

验证 Agent Workspace 在 OpenClaw 尚未受理请求前遇到反向隧道中断时具备以下行为：

1. 用户消息先持久化，浏览器连接不作为可靠性事实源；
2. 宿主离线时页面显示稳定的等待状态，不要求用户重复发送；
3. 隧道恢复后自动继续原请求；
4. 全过程只产生一个宿主运行，不重复执行；
5. 连接恢复轮次按持久化退避计数逐步放慢；
6. 隧道和守护任务在验收后恢复正常运行。

2. 精确终止对应的守护包装器、隧道包装器和反向转发 `ssh.exe`；
3. 在服务器使用 `ss` 确认 `127.0.0.1:18789` 无监听；
4. 从 Workspace 发送固定文本回复请求；
5. 页面观察到“请求已保存，正在连接智能体”和“恢复后会自动继续”；
6. 恢复隧道任务，再恢复守护任务；

## 6. 结论

通过。Agent Workspace 的受理前可靠投递已从调用栈内短重试升级为中心端持久状态机。常见反向
