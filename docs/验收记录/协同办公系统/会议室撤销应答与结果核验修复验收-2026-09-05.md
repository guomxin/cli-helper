## 三、修复及保护边界

1. 撤销入口兼容 HTTP 成功的空正文和 JSON `null`，读接口仍严格校验。
2. 请求应答和权威回读分离。请求发出后的解析错误、HTTP 错误、连接异常和拒绝应答都不能跳过回读；
   不因此重发撤销。最终只按业务事实判断，不能靠应答形式宣布成功。
3. “申请不存在”须由完整、无重复、无截断且总数稳定的本人申请列表证明；占用快照须包含目标会议室
   和有效数组，并与撤销前同一申请的占用基线对照。缺字段不能被当成空集合。
4. 分别保存应答阶段和回读阶段的安全诊断，不保存响应正文、凭据或临时卡片地址。
