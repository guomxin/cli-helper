## 2. 本机宿主自愈

### 2.1 实际模式

现有 `OpenClaw Gateway` 计划任务由管理员创建，当前普通用户不能修改其 ACL，因而没有强制改写
原任务。安装器自动采用无管理员权限的 `Startup Guard`：

- 每 15 秒检查 Gateway 监听和隧道任务；
- Gateway 缺失时启动既有 `OpenClaw Gateway` 任务；
- 隧道缺失时启动既有 `AgentBridge Workspace Tunnel` 任务；
- 使用命名互斥锁防止多个 Guard 实例；
- 状态写入 `%LOCALAPPDATA%\AgentBridge\openclaw-guard-status.json`；
- 不重放用户请求，不调用 AgentBridge 业务工具。

这使原 Gateway 任务的 72 小时执行上限不再形成持续中断：监听消失后 Guard 会重新启动任务。
