## 范围

依据用户确认的[视觉原型](../架构设计/管理控制台视觉原型/设计说明.md)，完成管理控制台而非 Agent Workspace 的前端改版。保留全部 11 个页面、原有管理接口及写操作确认边界。操作说明见[管理控制台](../平台能力/管理控制台.md)。

## 证据与复现

自动化入口：`tests/test_admin_frontend_browser.py`。设置 `AGENTBRIDGE_BROWSER_TESTS=1` 后执行；需要已安装 Playwright Python 包及 Chromium。默认测试套件不启动浏览器。

```powershell
$env:AGENTBRIDGE_BROWSER_TESTS = '1'
python -m pytest tests/test_admin_frontend_browser.py -q --basetemp output/pytest-admin-browser-unique
```

截图与浏览器结果 XML 存在本地 `output/admin-redesign-20260906/`。截图使用隔离测试库中的示例事件和测试用户，不是生产业务记录。运行中的服务器入口仍为 `https://10.10.50.213:8782`，具体发布版本以发布脚本回执为准。

本轮 Chrome 扩展在初始化时返回“failed to write kernel assets / 找不到指定路径”，因此浏览器验收使用独立 Chromium，不复用或修改用户 Chrome/OA 会话。没有重启 OpenClaw，也没有执行真实业务写入；不把测试库验收描述成生产管理员账号的实际操作验收。

## 测试中处理的问题

1. 切换页面的旧读取可能晚到：增加取消信号与页面版本检查。
2. 事件筛选后旧详情仍可见：清理不在筛选结果中的选中项，并阻断旧详情请求回填。
3. 重新登录可能继承上一账号页签：失效和退出时清理页面、事件、弹窗及提示状态。
4. 小屏图形箭头可能挤占文本：缩小连接符并保留固定列宽；两列分层展示。

## 尚未包含

- 本轮没有全量业务回归，不对 OA、日志、语雀、照明业务接口做改动。
- 无新增运行指标采集或服务在线探测，架构图不是实时流量图。
- 事件详情使用已存在的记录和关联链路，不推断缺失证据或自动处理未知写入。
- 真实管理员的管理写入不在生产环境试做；权限与确认链路由隔离测试和原有服务端测试验证。
