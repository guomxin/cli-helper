# 日志总结与事项复核

1. 先确认数据源、日期、人员或部门及是否含下级；区分 DAILY 日报周总结与 WEEKLY 周报。

2. 按获准标准查询或 content_analyze 读取正文；不要求自由 SQL。分页和长文片段必须读完，核对总数及版本。

3. 先逐篇拆分独立事项，再归纳主题；保留进展、进行中、计划、问题和未知。整篇工时不重复分配给各事项。

4. 输出范围和读取情况、主题概览、事项与来源、遗漏或待复核项。简要输出也不能把计划写成成果。

5. 使用 references/evidence.md 核对来源。记录读全不证明语义无遗漏。
